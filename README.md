# G. Sandeep – Academic Portfolio Website

A responsive static portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` – portfolio content and page structure
- `style.css` – responsive blue-and-white styling
- `script.js` – mobile navigation and current-year footer
- `assets/profile-photo.jpg` – supplied professional profile photograph

## Preview locally
1. Extract the ZIP file.
2. Open the `gsandeep_portfolio` folder.
3. Double-click `index.html` to open it in a browser.

No build tools or package installation are required.

## Publish free using GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `gsandeep-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub Pages finishes publishing, use the website URL shown in the Pages settings.

## Before publishing – personalize these placeholders
- Email, LinkedIn and ORCID details have been added from the information you supplied.
- Add a Google Scholar profile URL if you want it displayed.
- Add employment dates for the SNIST role.
- Verify publication status and complete authors, venue, year, volume/pages, DOI and indexing details.
- Add certifications only after confirming the certification details.
- Add any completed projects with an accurate title, description and technologies.
